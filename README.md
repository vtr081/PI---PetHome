
# 🐾 PetHome
> ## Uma plataforma web moderna para conectar canis/abrigos e pessoas interessadas em adotar ou apoiar a causa animal.

# 📌 Sobre o Projeto
> O PetHome nasceu como um PI e com o propósito de facilitar e incentivar o processo de adoção responsável de animais, além de oferecer suporte financeiro para canis e ONGs,
>A plataforma funciona como uma ponte entre instituições de acolhimento e futuros tutores,
>Os canis podem cadastrar seus perfis, publicar os animais disponíveis e receber doações diretas, Os usuários interessados criam seus perfis,
>navegam pelos animais cadastrados e passam por um formulário de triagem para garantir uma adoção consciente e segura.

# ✨ Funcionalidades Principais
## 🐕 Para os Canis / Abrigos
> * Perfil do Canil: Página própria com história, localização, dados de contato e informações para recebimento de doações.
> * Gestão de Animais: Cadastro, edição e remoção de pets disponíveis para adoção.
> * Recebimento de Doações: Integração para receber contribuições financeiras diretas dos usuários.
> * Avaliação de Adoções: Acesso às respostas do questionário dos interessados para aprovar ou recusar solicitações.

## 👤 Para os Usuários / Adotantes
> * Perfil do Usuário: Gerenciamento de informações pessoais e histórico de solicitações/doações.
> * Página Individual do Animal: Galeria de fotos, idade, porte, vacinas, temperamento e história do pet.
> * Processo de Triagem: Formulário dinâmico de perguntas sobre estilo de vida e ambiente residencial antes de enviar o pedido de adoção.
> * Doações: Possibilidade de ajudar financeira ou materialmente os canis cadastrados.
